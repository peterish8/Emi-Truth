## Quick start

```bash
git clone https://github.com/peterish8/Emi-Truth.git
cd Emi-Truth
npm install
npm run dev
```

Open `http://localhost:5173`.

### Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Local dev server |
| `npm run build` | Production build → `dist/` |
| `npm run preview` | Preview production build |
| `npm run lint` | ESLint |
| `npm run security:vercel` | Apply basic Vercel WAF rules (requires `vercel link`) |

No backend. No `.env` required for local dev.

## Deploy

Built for [Vercel](https://vercel.com):

1. Connect the GitHub repo
2. Framework preset: **Vite**
3. Build: `npm run build` → output `dist`
4. Add domains `emitruth.in` + `www.emitruth.in`
5. Enable **Web Analytics** and **Speed Insights** in the Vercel dashboard

`vercel.json` includes SPA rewrites so `/learn/*` and `/comics/*` work on direct visits.
