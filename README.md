<h2 align="center">🚀 Quick Start</h2>

```bash
git clone https://github.com/peterish8/Emi-Truth.git
cd Emi-Truth
npm install
npm run dev
```

<p align="center">
  Open <code>http://localhost:5173</code> — no backend, no <code>.env</code> needed.
</p>
